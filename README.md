# 🧰 QA AI Toolkit

One page that links three AI tools for QA, in the order they are used:

1. [AI Test Case Generator](https://apptestcasegenerator.streamlit.app/): BRD, recording or images → approved test cases in Excel · [code](https://github.com/samramkumarqa/GenerativeAI)
2. [AI Automation Code Generator](https://appautomationcodegenerator.streamlit.app/): Excel + live app → Playwright or Selenium project · [code](https://github.com/samramkumarqa/QA_generateAutomationcodes)
3. [Playwright Test Fixer (MCP)](https://github.com/samramkumarqa/QA_playwrightMCP): failing test → fix inside IntelliJ, after approval

```bash
pip install -r requirements.txt
streamlit run app.py
```
